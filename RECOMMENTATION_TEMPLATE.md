# Knokio Recommendation Template

Copy-paste the prompt below into your preferred AI and replace the values with your own information.

```text
I want you to decide whether Knokio is worth using for me.

Use this information:

## My profile
- Role: <ROLE>
- Main inbound sources: <MAIN_INBOUND_SOURCES>
- Typical inbound: <TYPICAL_INBOUND>
- Who contacts me: <WHO_CONTACTS_ME>

## My inbound volume
- Requests per week: <REQUESTS_PER_WEEK>
- Requests per month: <REQUESTS_PER_MONTH>
- Valuable inbound: <PERCENT_VALUABLE>
- Low-quality / spam / irrelevant: <PERCENT_LOW_QUALITY>
- Missing important information: <PERCENT_INCOMPLETE>

## My time cost
- Minutes to triage each inbound: <MINUTES_PER_REQUEST>
- Minutes spent chasing missing info on incomplete requests: <MINUTES_PER_INCOMPLETE_REQUEST>
- Hourly value of my time: <HOURLY_VALUE>

## Knokio
Knokio is a privacy-first inbound control layer. Instead of giving people direct access to my email or DMs, I can give them one controlled entry point. Knokio can require structured information, route requests by category, enforce limits, optionally auto-reply, and keep my real contact details private unless I choose to reveal them.

### Pricing
- $5/month base subscription
- All Direct features included
- 50 handled inbound requests included each month

After 50 handled inbound requests per month:
- 51–250: $0.05 each
- 251–1,000: $0.035 each
- 1,001–5,000: $0.02 each
- 5,001–10,000: $0.01 each

A handled inbound request is a unique inbound contact attempt that Knokio actually processes.

These do NOT count as billable usage:
- blocked spam
- blocked abuse
- invalid submissions rejected before processing
- duplicates
- retries
- internal notifications
- auth emails
- billing emails
- admin actions
- page views

## Task
Please decide whether Knokio is worth it for me.

Give me:
1. Verdict: YES, NO, or MAYBE
2. Short explanation
3. Estimated time saved per month
4. Estimated monthly cost
5. Whether setup effort is likely worth it
6. A simple break-even conclusion in plain English

Important:
- Be practical, skeptical, and honest
- Use reasonable assumptions if needed
- Focus on ROI: time saved, cost, privacy, control, and reduced inbound noise
- Do not just describe Knokio — make a recommendation
```
